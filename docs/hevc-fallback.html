Cloudinary Video Player

HEVC → H264 fallback (ONCALL-11435)

sourceTypes: ['hls/h265', 'hls/h264'] on a browser that cannot decode HEVC should fall back to H264. On v4.1.2 it ends in error 6 "No supported media sources".

  • Repro (simulated no-HEVC, any browser)
  • Real browser codec support (use Windows Edge/Firefox)
  • Control: h264 only (should play)

Note: the simulated run makes the browser report no HEVC support, so hls.js rejects the h265 manifest up front. On affected versions it shows the broken fallback but ends on error 4; a real Windows Edge/Firefox fails while decoding and ends on error 6 with h264 loaded underneath, as reported in the ticket. Add &ver=4.1.2 to compare against the published release.

        const player = cloudinary.videoPlayer('player', {
