Delivery formats

Deliver videos as-is

By default the player adds f_auto:video to every URL, so Cloudinary picks the best format for each browser. Set sourceTypes: [''] to skip it and deliver the stored file unchanged.

When to use it

Good fit

  • You want the exact bytes you uploaded, for example for compliance or archival viewing.
  • Your files are already web-ready (for example MP4 with H.264), and you want to avoid format-conversion transformations.

Trade-offs

  • No format optimization. Files are often much larger, which costs more bandwidth and loads more slowly. Compare the sizes above.
  • The browser must support the original container and codec. A .mov or HEVC upload may not play everywhere.
  • Account-level optimization settings, such as optimize by default, still apply to the URL.

How sourceTypes changes the URL

Delivery URLs for sea_turtle
Configuration Delivered path Result
sourceTypes: ['auto'] (default) f_auto:video/sea_turtle Best format for each browser
sourceTypes: ['mp4'] sea_turtle.mp4 Converted to MP4 if needed
sourceTypes: [''] sea_turtle Original file, unchanged

Example code

Set it on the player to apply it to every source, or on a single source.

// Every source in this player
const player = cloudinary.videoPlayer('player', {
  cloudName: 'demo',
  sourceTypes: ['']
});

// Or a single source
player.source('sea_turtle', { sourceTypes: [''] });
